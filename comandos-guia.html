Comandos en Minecraft

📌 Sintaxis Básica

Los comandos en Minecraft siguen esta estructura general:

/[comando] [argumentos...]

Comandos Básicos

Comando Descripción Ejemplo
/gamemode Cambia el modo de juego /gamemode creative @p
/tp Teletransporta jugadores /tp Jugador1 100 64 100
/give Da items a un jugador /give @p diamond 64
/time Cambia la hora del mundo /time set day
/weather Cambia el clima /weather clear 6000

Selectores de Jugadores

Selector Descripción Ejemplo
@p Jugador más cercano /give @p diamond
@r Jugador aleatorio /tp @r 0 64 0
@a Todos los jugadores /say @a Mensaje para todos
@e Todas las entidades /kill @e[type=minecraft:zombie]
@s El ejecutor del comando /execute as @a run say @s

Comandos Avanzados

Comando /execute

# Ejecutar comando como otro jugador
/execute as @a run say Hola desde execute

# Ejecutar en posición específica
/execute positioned 100 64 100 run setblock ~ ~ ~ minecraft:diamond_block

# Ejecutar condicionalmente
/execute if entity @p[distance=..10] run say Hay jugadores cerca

# Encadenar ejecuciones
/execute as @a at @s if block ~ ~-1 ~ minecraft:grass_block run give @s diamond 1

Comando /data

# Obtener datos de una entidad
/data get entity @p

# Modificar datos de un bloque
/data merge block 100 64 100 {CustomName:'{"text":"Bloque Especial"}'}

# Copiar datos entre entidades
/data modify entity @e[type=minecraft:zombie,limit=1] CustomName set from entity @p CustomName

Crear Comandos Personalizados con Functions

Ejemplo: Sistema de Inicio de Sesión

Crea un archivo login.mcfunction:

# login.mcfunction
# Sistema de bienvenida

# Mensajes
tellraw @s {"text":"=== BIENVENIDO AL SERVIDOR ===","color":"gold","bold":true}
tellraw @s {"text":"Tienes 5 minutos para registrarte","color":"yellow"}

# Dar items iniciales
give @s minecraft:bread 16
give @s minecraft:wooden_pickaxe 1
give @s minecraft:wooden_sword 1

# Efectos de bienvenida
effect @s minecraft:speed 30 0
effect @s minecraft:haste 30 0

# Teletransportar al spawn
spreadplayers 0 0 100 200 false @s

# Guardar punto de spawn
spawnpoint @s

Sistema de Recompensas Diarias

# daily_reward.mcfunction
# Sistema de recompensas diarias

# Verificar si ya reclamó hoy
scoreboard players add @s daily_cooldown 0
execute if score @s daily_cooldown matches 1.. run tellraw @s {"text":"Ya reclamaste tu recompensa hoy","color":"red"}

# Si no ha reclamado
execute unless score @s daily_cooldown matches 1.. run tellraw @s {"text":"¡Recompensa diaria reclamada!","color":"green"}
execute unless score @s daily_cooldown matches 1.. run give @s minecraft:diamond 5
execute unless score @s daily_cooldown matches 1.. run give @s minecraft:emerald 10
execute unless score @s daily_cooldown matches 1.. run experience add @s 100
execute unless score @s daily_cooldown matches 1.. run scoreboard players set @s daily_cooldown 1

# Programar reset diario (en otro archivo)
# reset_daily.mcfunction
scoreboard players set @a daily_cooldown 0
tellraw @a {"text":"¡Las recompensas diarias se han reiniciado!","color":"green"}

Mini-juego: Parkour con Comandos

# parkour_start.mcfunction
# Iniciar parkour

# Configurar jugador
gamemode adventure @s
tp @s -100 65 -100

# Guardar checkpoint inicial
scoreboard players set @s checkpoint 1
data merge entity @s {Pos:[-100.0,65.0,-100.0]}

# Mensajes
tellraw @s {"text":"=== PARKOUR CHALLENGE ===","color":"gold"}
tellraw @s {"text":"Llega al final para ganar recompensas","color":"yellow"}

# parkour_checkpoint.mcfunction
# Sistema de checkpoints

# Checkpoint 1
execute positioned -50 70 -50 run tellraw @s {"text":"Checkpoint 1 alcanzado","color":"green"}
execute positioned -50 70 -50 run scoreboard players set @s checkpoint 2

# Checkpoint 2
execute positioned 0 80 0 run tellraw @s {"text":"Checkpoint 2 alcanzado","color":"green"}
execute positioned 0 80 0 run scoreboard players set @s checkpoint 3

# Final
execute positioned 100 90 100 run tellraw @s {"text":"¡COMPLETASTE EL PARKOUR!","color":"gold","bold":true}
execute positioned 100 90 100 run give @s minecraft:diamond 10
execute positioned 100 90 100 run effect @s minecraft:levitation 5 0

# parkour_reset.mcfunction
# Resetear si cae al vacío

execute if entity @s[y=-10] run tp @s -100 65 -100
execute if entity @s[y=-10] run tellraw @s {"text":"Has caído, reiniciando...","color":"red"}

Sistema de Títulos y Subtítulos

# titles.mcfunction
# Sistema de títulos

# Título principal
title @s title {"text":"MINECRAFT DEV","color":"gold","bold":true}

# Subtítulo
title @s subtitle {"text":"Guía de comandos","color":"yellow"}

# Título con acción
title @s actionbar {"text":"¡Bienvenido al servidor!","color":"green"}

# Títulos en secuencia
schedule function titles:wave1 1s
schedule function titles:wave2 3s
schedule function titles:wave3 5s

# wave1.mcfunction
title @a title {"text":"OLA 1","color":"red"}
title @a subtitle {"text":"¡Prepárate!","color":"yellow"}
playsound minecraft:entity.ender_dragon.growl master @a

# wave2.mcfunction
title @a title {"text":"OLA 2","color":"red"}
title @a subtitle {"text":"¡Más difícil!","color":"yellow"}
summon minecraft:zombie ~ ~ ~
summon minecraft:skeleton ~ ~ ~

# wave3.mcfunction
title @a title {"text":"OLA FINAL","color":"red","bold":true}
title @a subtitle {"text":"¡BOSS!","color":"yellow"}
summon minecraft:evoker ~ ~ ~

Sistema de Partículas y Efectos

# particles.mcfunction
# Sistema de partículas

# Partículas alrededor del jugador
execute at @a run particle minecraft:portal ~ ~1 ~ 0.5 1 0.5 0.1 50

# Partículas en área específica
particle minecraft:dust 1 0 0 1 100 200 64 100 10 20 20 0.1 50

# Efectos visuales para eventos
execute at @e[type=minecraft:zombie] run particle minecraft:angry_villager ~ ~1 ~ 0.5 0.5 0.5 0 5

# Luz de beam para tesoros
execute positioned ~ ~-1 ~ run particle minecraft:end_rod ~ ~1 ~ 0 0 0 0.1 100
execute positioned ~ ~-1 ~ run particle minecraft:fireworks_spark ~ ~2 ~ 0 0 0 0.1 50

📚 Consejos Profesionales

  • Usa scoreboard para variables persistentes
  • Combina execute con condiciones para lógica compleja
  • Programa funciones con schedule para temporizadores
  • Usa data merge para modificar NBT de entidades
  • Optimiza comandos usando execute if antes de acciones costosas
