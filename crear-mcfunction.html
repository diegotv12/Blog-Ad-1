Guía Completa de McFunctions

📌 ¿Qué son las McFunctions?

Las funciones (.mcfunction) son archivos de texto que contienen una lista de comandos que se ejecutan secuencialmente. Son la base para crear sistemas complejos en Minecraft.

Estructura de Archivos

# Estructura de un datapack
datapack_name/
├── pack.mcmeta
└── data/
    └── namespace/
        ├── functions/
        │   ├── example.mcfunction
        │   └── subfolder/
        │       └── another.mcfunction
        └── tags/
            └── functions/
                └── tick.json

pack.mcmeta

{
    "pack": {
        "pack_format": 15,
        "description": "Mi datapack de funciones"
    }
}

Funciones Básicas

# welcome.mcfunction
# Función de bienvenida

say ¡Bienvenido al servidor!
give @s minecraft:compass 1
give @s minecraft:bread 16
effect @s minecraft:speed 30 0
title @s title {"text":"¡Bienvenido!","color":"gold"}

Sistema de Scoreboards

# setup_scoreboards.mcfunction
# Crear scoreboards para estadísticas

scoreboard objectives add deaths deathCount "Muertes"
scoreboard objectives add kills playerKillCount "Asesinatos"
scoreboard objectives add playtime minecraft.custom:minecraft.play_time "Tiempo Jugado"
scoreboard objectives add money dummy "Dinero"
scoreboard objectives add level dummy "Nivel"

# Mostrar en sidebar
scoreboard objectives setdisplay sidebar kills

Sistema de Niveles

# level_system.mcfunction
# Sistema de niveles basado en kills

# Obtener kills actuales
execute store result score @s kills run scoreboard players get @s kills

# Calcular nivel (cada 10 kills = 1 nivel)
scoreboard players operation @s level = @s kills
scoreboard players operation @s level /= @s const_10

# Dar recompensas por nivel
execute if score @s level matches 1 run give @s minecraft:iron_ingot 5
execute if score @s level matches 5 run give @s minecraft:diamond 1
execute if score @s level matches 10 run give @s minecraft:netherite_ingot 1

# Mensaje de subida de nivel
execute if score @s level matches 1.. run tellraw @s [{"text":"¡Has subido al nivel ","color":"green"},{"score":{"name":"@s","objective":"level"}}]

Sistema de Economía

# economy.mcfunction
# Sistema de dinero

# Ver dinero
tellraw @s [{"text":"Tu dinero: $","color":"gold"},{"score":{"name":"@s","objective":"money"}}]

# Añadir dinero
scoreboard players add @s money 100
tellraw @s {"text":"+$100","color":"green"}

# Quitar dinero (con verificación)
execute if score @s money matches 500.. run scoreboard players remove @s money 500
execute if score @s money matches 500.. run give @s minecraft:diamond 1
execute unless score @s money matches 500.. run tellraw @s {"text":"No tienes suficiente dinero","color":"red"}

Eventos Programados (Tick)

# tick.json (tags/functions/tick.json)
{
    "values": [
        "namespace:check_players",
        "namespace:auto_save",
        "namespace:particle_effects"
    ]
}

# check_players.mcfunction
# Ejecuta cada tick (20 veces por segundo)

# Contar jugadores
execute if entity @a[limit=1] run say Hay jugadores en el servidor
execute unless entity @a[limit=1] run say Servidor vacío

# Dar efectos en área
effect give @a[distance=..10] minecraft:regeneration 1 0
effect give @a[distance=..50] minecraft:speed 1 0

# check_afk.mcfunction
# Detectar jugadores AFK

# Marcar tiempo de última actividad
scoreboard players add @a afk_time 1

# Resetear tiempo cuando se mueven
execute as @a at @s if entity @s[x=~,y=~,z=~,dx=0,dy=0,dz=0] run scoreboard players set @s afk_time 0

# Kickear después de 5 minutos (6000 ticks)
execute as @a if score @s afk_time matches 6000.. run kick @s Has estado AFK demasiado tiempo

Sistema de Misiones (Quests)

# quest_system.mcfunction
# Sistema de misiones

# Iniciar misión
scoreboard players set @s quest_active 1
scoreboard players set @s quest_progress 0
tellraw @s {"text":"¡Misión iniciada: Mata 10 zombies!","color":"green"}

# quest_progress.mcfunction
# Ejecutar cuando matan un zombie

execute if score @s quest_active matches 1 run scoreboard players add @s quest_progress 1
execute if score @s quest_progress matches 10.. run function quest:complete

# quest_complete.mcfunction
# Completar misión

tellraw @s {"text":"¡Misión completada!","color":"gold","bold":true}
give @s minecraft:diamond 5
give @s minecraft:emerald 10
scoreboard players set @s quest_active 0
scoreboard players set @s quest_progress 0

Sistema de Protección

# protection.mcfunction
# Sistema de protección de áreas

# Definir área protegida
execute positioned 100 64 100 run function protection:check_area

# check_area.mcfunction
# Verificar si puede construir

execute positioned ~ ~ ~ run function protection:can_build

# can_build.mcfunction
# Permitir solo a ciertos jugadores

execute if entity @p[tag=admin] run setblock ~ ~ ~ minecraft:stone
execute unless entity @p[tag=admin] run tellraw @p {"text":"No puedes construir aquí","color":"red"}

# protection_region.mcfunction
# Proteger región específica

# Detectar entrada/salida
execute as @a at @s if entity @s[x=100,y=64,z=100,dx=50,dy=20,dz=50] run tag @s add in_region
execute as @a at @s unless entity @s[x=100,y=64,z=100,dx=50,dy=20,dz=50] run tag @s remove in_region

# Aplicar reglas dentro de la región
execute as @a[tag=in_region] at @s run effect @s minecraft:resistance 1 0
execute as @a[tag=in_region] at @s run effect @s minecraft:regeneration 1 0

💡 Mejores Prácticas

  • Organización: Usa carpetas para diferentes sistemas
  • Optimización: Limita las funciones en tick a lo esencial
  • Debug: Usa say y tellraw para probar
  • Compatibilidad: Usa namespaces únicos para evitar conflictos
  • Documentación: Comenta tus funciones para mantenerlas claras

Ejemplo Completo: Datapack de Bienvenida

# Estructura final del datapack
welcome_datapack/
├── pack.mcmeta
└── data/
    └── welcome/
        ├── functions/
        │   ├── init.mcfunction
        │   ├── join.mcfunction
        │   ├── give_items.mcfunction
        │   └── spawn_protection.mcfunction
        └── tags/
            └── functions/
                └── tick.json

# init.mcfunction
scoreboard objectives add first_join dummy
say Datapack de bienvenida cargado

# join.mcfunction
execute unless score @s first_join matches 1 run function welcome:give_items
scoreboard players set @s first_join 1

# give_items.mcfunction
give @s minecraft:wooden_sword 1
give @s minecraft:cooked_beef 16
give @s minecraft:torch 32
title @s title {"text":"¡Bienvenido!","color":"gold"}
playsound minecraft:entity.player.levelup master @s

# tick.json
{
    "values": [
        "welcome:spawn_protection"
    ]
}

# spawn_protection.mcfunction
execute as @a at @s positioned 0 64 0 run function welcome:protect

# protect.mcfunction
execute if entity @s[distance=..10] run effect @s minecraft:resistance 1 0
execute if entity @s[distance=..10] run effect @s minecraft:regeneration 1 0
execute if entity @s[distance=..10] run effect @s minecraft:saturation 1 0
